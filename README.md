# РУСФИНАНС — презентация концепции сайта

Интерактивная презентация концепции сайта для производителя модульных зданий.
Подготовлено агентством **NORVALDA**.

**Смотреть:** https://salesnorvalda.github.io/rusfinans-concept/

Рассчитана на большой экран (ноутбук / десктоп).

## Управление

- Колесо мыши или стрелки — по листам
- Перетаскивание — свободный полёт по столу проекта
- Миникарта справа внизу — клик = перелёт
- Двойной клик по предмету — прицельный зум
- Клавиши 0–9 — прыжок к листу, P — автопоказ

Один HTML-файл + папка изображений, без библиотек и сборки.
